# ras-robo-literario
Este projeto consiste no desenvolvimento de um robô educacional focado em tornar o aprendizado de literatura mais interativo, lúdico e dinâmico. O público-alvo principal são alunos do 6° e 7° ano do Ensino Fundamental II, estimulando o trabalho em equipe e a interpretação de texto por meio de uma gincana pedagógica gamificada.
